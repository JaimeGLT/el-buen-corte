# Tecnologías Utilizadas en el Frontend

## Framework y Lenguaje
- **React 19**: Librería para construir interfaces de usuario, con hooks y componentes funcionales.
- **TypeScript**: Superset de JavaScript para tipado estático, mejora mantenibilidad.

## Herramientas de Desarrollo
- **Vite**: Build tool rápida para desarrollo y bundling.
- **ESLint**: Linting para código limpio.
- **Tailwind CSS**: Framework CSS utility-first para estilos responsivos.

## Librerías Principales
- **React Router DOM**: Para navegación SPA.
- **Axios**: Cliente HTTP para llamadas a API.
- **React Hook Form**: Manejo de formularios con validación.
- **Zod**: Validación de esquemas para forms y datos.
- **Chart.js**: Gráficos para reportes (con react-chartjs-2 implícito).
- **JWT Decode**: Decodificar tokens JWT.
- **React Hot Toast**: Notificaciones.
- **Lucide React**: Iconos.
- **React to Print**: Imprimir recibos.

## Gestión de Estado
- **Context API**: Para estado global (autenticación).
- **Hooks Personalizados**: Para fetches (getHook.ts).

## Estilos y UI
- **Tailwind CSS**: Estilos inline con clases utilitarias.
- **Componentes Reutilizables**: Botones, inputs, modales, etc.

## Otras Dependencias
- **@hookform/resolvers**: Integración Zod con React Hook Form.
- **@tailwindcss/vite**: Plugin para Vite.

Esta pila permite un desarrollo moderno, rápido y mantenible para una SPA compleja.
