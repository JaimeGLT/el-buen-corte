# Mejores Prácticas en el Frontend

## Desarrollo
- Usar TypeScript para tipado.
- Componentes funcionales con hooks.
- Separar lógica de UI.
- Validar forms con Zod.

## Rendimiento
- Memoizar componentes pesados.
- Lazy loading para rutas.
- Optimizar imágenes.

## Seguridad
- No almacenar datos sensibles en localStorage (solo JWT).
- Sanitizar inputs.
- Usar HTTPS.

## Accesibilidad
- Etiquetas en forms.
- Navegación por teclado.
- Contraste de colores.

## Testing
- Tests con Jest/React Testing Library.
- Cobertura en componentes críticos.

## Código
- ESLint para consistencia.
- Nombres descriptivos.
- Comentarios en lógica compleja.
