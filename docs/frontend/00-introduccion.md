# Introducción al Frontend

El frontend del proyecto "proyecto_erp_el_buen_corte" es una aplicación web desarrollada con React y TypeScript, diseñada para proporcionar una interfaz de usuario intuitiva para gestionar las operaciones de la peluquería "El Buen Corte". Permite a los usuarios (staff) administrar clientes, citas, inventario, pagos y generar reportes a través de una interfaz moderna y responsiva.

## Propósito
- Ofrecer una UI amigable para interactuar con el backend API.
- Gestionar operaciones diarias de la peluquería.
- Proporcionar dashboards y reportes visuales.
- Asegurar experiencia de usuario fluida con autenticación.

## Funcionalidades Principales
- **Autenticación**: Login para staff con roles.
- **Dashboard**: Vista general con métricas y gráficos.
- **Gestión de Clientes**: CRUD de clientes con detalles.
- **Citas**: Programar, editar y gestionar citas.
- **Inventario**: Control de productos y movimientos.
- **Pagos**: Registro y gestión de pagos.
- **Personal**: Administración de estilistas.
- **Reportes**: Gráficos y análisis de datos.

## Arquitectura General
- **SPA (Single Page Application)**: Navegación sin recargas.
- **Componentes Reutilizables**: Basados en React con hooks.
- **Estado Global**: Context API para autenticación.
- **Estilos**: Tailwind CSS para diseño moderno.
- **Rutas Protegidas**: Solo usuarios autenticados acceden.

## Tecnologías Clave
- React 19, TypeScript, Vite, Tailwind CSS, Axios, React Router, Chart.js, Zod, React Hook Form.

Este frontend complementa el backend, ofreciendo una experiencia completa para el ERP de la peluquería.
