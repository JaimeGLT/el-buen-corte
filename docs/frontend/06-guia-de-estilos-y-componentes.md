# Guía de Estilos y Componentes

## Estilos
- **Tailwind CSS**: Clases utilitarias para diseño responsivo.
- **Colores**: Tema neutro, grises y azules.
- **Layout**: Flexbox/Grid para layouts.
- **Responsive**: Breakpoints sm/md/lg/xl.

## Componentes Reutilizables
- **Button**: Variantes (primary, secondary), tamaños.
- **Input/TextArea/Select**: Form controls con Tailwind.
- **Modal**: Overlay con contenido centrado.
- **Sidebar**: Navegación lateral colapsable.
- **Charts**: Bar, Line, Pie con Chart.js.

## Guía de Uso
- Usar componentes consistentes.
- Nombrado: PascalCase para componentes.
- Props tipados con TypeScript.

## Notas
- Mantener consistencia visual.
- Accesibilidad básica (alt en imágenes, focus).
